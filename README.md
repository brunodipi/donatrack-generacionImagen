# Donatrack generacionImagen
En este repo está el aspecto de generacion de imagenes de insignias para el TP Donatrack.

Como no funcionaba el nodo de codigo de python de N8N creamos un codigo PY aparte y lo subimos como una API en [Render](https://render.com)
La API se mantiene activa con UptimeRobot

[Documentacion](https://donatrack-generacionimagen.onrender.com/docs)
